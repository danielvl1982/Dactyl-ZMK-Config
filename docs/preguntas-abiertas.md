# Preguntas abiertas

Points that cannot be confirmed from the code alone, and inconsistencies found while documenting. They stay marked as "inferred from code" in the rest of the documentation until answered. Global, stable numbering: items are never renumbered; resolved ones are struck through and kept.

## Negocio y datos
